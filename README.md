# 每日激励站 · Daily Inspire

> **愿你成为想成为的人。**
> 一个对抗懒散、沉淀自律的「晨启晚收」仪式感产品 —— 深色高级感 · 金句置顶 · 卡片式布局 · 纯本地运行。

---

## 一、核心体验

| 时段 | 仪式 |
| --- | --- |
| 🌅 晨间 | 全屏金句 + 榜样视觉 + 一键开启配乐，唤醒一天 |
| ☀️ 日间 | 愿景板 / 榜样区 / 今日目标 / 打卡追踪 / 觉醒便签 |
| 🌙 晚间 | 睡前复盘：写下今天最棒的瞬间 |

晨启晚收，形成每日闭环 —— 温柔鼓励，而非生硬催促。

---

## 二、功能清单

- **晨间启动页**：大字号金句置顶 + 榜样图沉浸展示 + 开启配乐
- **愿景板**：三板块卡片式布局，自由编辑你的长期愿景
- **榜样视觉区**：支持分组展示（含甲木日主分组），放入榜样图片时刻激励自己
- **今日目标**：写下今天的一个小行动，聚焦当下
- **打卡追踪**：日历视图记录每日打卡，看得见的坚持
- **觉醒便签**：随手记录此刻的灵感 / 觉醒瞬间，可编辑沉淀
- **晚间复盘**：今天最棒的瞬间是什么？对标感恩日记
- **BGM 库**：IndexedDB 存储 + 悬浮播放条 + 场景分类，导入你刷到就上头的音乐

## 四、本地使用

1. 下载仓库中的 `index.html`
2. 双击用浏览器打开即可使用
3. 所有数据保存在本地（localStorage / IndexedDB），不依赖任何服务器

---

## 五、技术栈

- 单文件 HTML + CSS + 原生 JavaScript，零外部依赖
- localStorage / IndexedDB 本地持久化
- 支持一键部署到 GitHub Pages

---

## 六、设计理念

- **深色高级感**：低调的暗色背景 + 金色点缀，简约有力
- **大字号金句置顶**：让每天的第一眼充满力量
- **卡片式布局**：信息分层清晰，操作直觉化
- **晨启晚收闭环**：晨间启动 + 晚间复盘，形成每日仪式感与动力
